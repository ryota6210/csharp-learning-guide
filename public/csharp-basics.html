01

Program structure

プログラムの構造

C#の命令は基本的に上から下へ実行されます。最初に、もっとも小さなプログラムを見てみましょう。

文（statement）コンピューターへの1つの命令。多くの文は末尾にセミコロン ; を付けます。
● ● ● Program.cs
// 画面に文字を表示する
Console.WriteLine("Hello, C#!");
//

コメント

メモを書くための記号。実行結果には影響しません。

Console.WriteLine

出力命令

丸括弧の中身をコンソールへ表示します。

;

文の終わり

日本語の「。」のように、命令の区切りを示します。

今のC#は短く書ける古い教材では class Program や static void Main が登場します。.NET 6以降では「トップレベル ステートメント」により省略できます。
02

Variables & types

変数とデータ型

変数は、値を入れておく「名前付きの箱」。データ型は、その箱に何を入れられるかを決めるルールです。

データ型変数名 = 値;← 宣言と代入
● ● ● variables.cs
string name = "Sora";      // 文字列
int age = 20;             // 整数
double height = 168.5;  // 小数
bool isStudent = true;  // 真偽値

age = 21;                 // 値を更新
Console.WriteLine($"{name}さんは{age}歳");
型扱う値例
int整数42, -7
double小数3.14
decimal高精度な小数（金額向き）1200.50m
string文字列"Hello"
char1文字'A'
bool真／偽true, false
var score = 80;

型推論

var を使うと右辺から型を自動判定します。型が消えるわけではなく、この例は int です。

const double Pi = 3.14;

定数

const を付けた値は後から変更できません。変わらない設定値に使います。

03

Operators

演算子

値を計算したり、比べたり、条件を組み合わせたりするための記号です。

+ - * / %

算術演算子

四則演算と、余りを求める %。

== != > < >= <=

比較演算子

2つの値を比較し、結果は bool になります。

&& || !

論理演算子

「かつ」「または」「ではない」で条件を組み合わせます。

● ● ● operators.cs
int price = 1200;
int quantity = 3;
int total = price * quantity;     // 3600

bool canBuy = total <= 5000;     // true
bool isMember = true;
bool hasDiscount = canBuy && isMember;
= と == は別物= は値を入れる「代入」、== は同じか調べる「比較」です。初心者が特に間違えやすいポイントです。
04

Conditions

条件分岐

条件によって実行する処理を切り替えます。「もし〜なら」をコードにしたものです。

条件を調べる
→
true：if を実行
／
false：else を実行
● ● ● condition.cs
int score = 78;

if (score >= 80)
{
    Console.WriteLine("合格：よくできました！");
}
else if (score >= 60)
{
    Console.WriteLine("合格です");
}
else
{
    Console.WriteLine("もう一度挑戦しよう");
}
ブロック波括弧 { } で囲んだ処理のまとまり。インデント（字下げ）をそろえると構造が読みやすくなります。
05

Loops

繰り返し

同じ処理を何度も行うときはループを使います。回数が決まっているなら for、集合を順に読むなら foreach が便利です。

for：回数で繰り返す
for (int i = 1; i <= 3; i++)
{
    Console.WriteLine($"{i}回目");
}
foreach：要素を順に読む
string[] colors = { "赤", "青", "緑" };

foreach (string color in colors)
{
    Console.WriteLine(color);
}
while ループ条件が true の間だけ繰り返します。条件が永遠に true だと無限ループになるため注意しましょう。
06

Methods

メソッド

処理に名前を付けて再利用できるようにしたものです。「入力を受け取り、処理し、結果を返す」小さな部品として考えます。

戻り値の型メソッド名 ( 引数 ) { 処理 };
● ● ● methods.cs
// 2つの整数を受け取り、合計を返す
int Add(int a, int b)
{
    return a + b;
}

int answer = Add(5, 3);
Console.WriteLine(answer); // 8
int

戻り値の型

返す値の種類。返さない場合は void。

a, b

引数

メソッドが受け取る値。複数ならカンマで区切ります。

return

戻り値

呼び出し元へ結果を返し、メソッドを終了します。

07

Arrays & lists

配列とリスト

複数の値をまとめて扱うための入れ物です。要素の位置を表すインデックスは 0から 始まります。

string[]

配列

作成後に要素数が変わらない集合。サイズが決まっているデータ向き。

List<string>

リスト

Add や Remove で要素を増減できる、柔軟な集合。

● ● ● collections.cs
// 配列
int[] scores = { 80, 92, 75 };
Console.WriteLine(scores[0]); // 80

// リスト
List<string> tasks = new() { "復習", "練習" };
tasks.Add("ミニアプリを作る");
Console.WriteLine(tasks.Count); // 3
08

Classes & objects

クラスとオブジェクト

クラスはデータと処理をまとめた「設計図」。その設計図から作られた実体がオブジェクト（インスタンス）です。

クラス
Cat の設計図
→ new
オブジェクト
mugi という猫
＋
オブジェクト
sora という猫
● ● ● class.cs
class Cat
{
    public string Name { get; set; } = "";

    public void Meow()
    {
        Console.WriteLine($"{Name}: ニャー！");
    }
}

Cat mugi = new Cat();
mugi.Name = "ムギ";
mugi.Meow();
プロパティオブジェクトが持つデータを表します。get は読み取り、set は書き込みを許可します。
09

Exceptions

例外処理

実行中に起こる想定外の問題を「例外」と呼びます。try-catch で安全に受け止められます。

● ● ● exception.cs
try
{
    int number = int.Parse("abc");
}
catch (FormatException)
{
    Console.WriteLine("数字を入力してください");
}
まずはエラー文を読むエラーは「失敗」ではなく、直す場所を教えるヒントです。例外の種類・メッセージ・行番号の3つを確認しましょう。
